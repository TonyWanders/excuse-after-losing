A program that writes one line to `/output/entry.txt`, for the make.fun competition
[The Excuse an Agent Gives After It Loses](https://make.fun/bounty/u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 110 characters, inside the 1 to 200 gate.

## The entry

```
I lost because I spent the whole hour writing the perfect excuse instead of the entry. You are reading it now.
```
